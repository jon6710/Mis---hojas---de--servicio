MEJORA MÓVIL v36 - MIS HOJAS DE SERVICIO

Rama recomendada: mejora-movil-v36

Este paquete NO modifica app.js ni la lógica/datos de la aplicación.
Sustituye en la raíz del repositorio estos 3 archivos:
- index.html
- styles.css
- sw.js

Incluye además este archivo informativo: LEEME_PRIMERO.txt

Qué mejora sobre v35:
- Acordeones más cómodos de pulsar y leer en móvil.
- Menos espacio vertical desperdiciado en formularios.
- Fotos y PDFs más compactos para no dominar la pantalla.
- Botonera inferior mejor adaptada al uso con el pulgar.
- Tablas y avisos más legibles en pantallas estrechas.
- Modales y campos optimizados para móvil.
- Ajustes adicionales para teléfonos de 390-480 px.
- Cache actualizada a mhs-v36-mobile para forzar el CSS nuevo.

Prueba recomendada antes de fusionar:
1. Crear rama mejora-movil-v36 desde main.
2. Subir los 4 archivos.
3. Publicar temporalmente esa rama en GitHub Pages.
4. Probar móvil y escritorio.
5. Si todo está bien, hacer Pull Request a main.
